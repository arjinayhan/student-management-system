Student Management System

The Student ManagProject Description

ement System is a Python-based project designed to manage student information, course registrations, instructors, and academic departments.

The project demonstrates Object-Oriented Programming (OOP) concepts such as classes, objects, attributes, methods, and relationships between classes.

Features

Manage student information.

Register students for courses.

Drop registered courses.

Assign grades to students.

Calculate students' weighted average grades (GPA).

Manage courses and instructors.

Organize courses and instructors by department.

Class Structure

The project consists of five main classes:

Student: Stores student information and manages course registrations and GPA calculations.

Course: Stores course details such as course ID, name, and credits.

Enrollment: Manages student course registrations, semesters, and grades.

Instructor: Stores instructor information and assigned courses.

Department: Manages department information, courses, and instructors.
